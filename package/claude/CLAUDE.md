# CLAUDE.md

## PR レビューコメントへの返信

返信には、相手が次の判断（スレッドを解決するか、押し返すか）に必要な情報から、相手の手元にすでにある情報（相手自身の指摘、差分、コミット、PR 本文）を引いた分だけを書く。

| 返信の種類 | 相手に足りない情報 | 分量の目安 |
| --- | --- | --- |
| 依頼どおりに対応した | どのコミットを見ればよいか | 1 文（何を変えたか＋コミットハッシュ） |
| 依頼と違う形で対応した | どこが違い、なぜそうしたか | 2 文 |
| 見送る | 納得できる理由と、どこで扱うか | 1〜2 文（理由 → 結論、参照は 1 つ） |
| 質問に答える | 答えと、相手が自分で辿れない根拠 | 答え 1 文＋根拠 |
| 指摘に反論する | 主張と、それを支える決め手 1 つ | 2〜3 文 |

- 文脈として足すのは、相手が知らない決定や事情だけにする（一言とリンク）。
- 指摘の言い直し、差分を読めば分かる変更内容、検証の経緯、非を認める前置きは書かない。
- 書いたあと、各文に「消したら相手は聞き返すか」を当て、聞き返さない文は消す。
- レビュー本文（総評）に書かれた懸念には、求められない限り返信しない。
- 投稿する前に、返信案を必ずユーザーに見せる。

例:

- 対応した: 「`SAFE_CAST(ROUND(...) AS INT64)` に ae2de44 で変更しました！」
- 見送る: 「〜に揃えると壊れた値が既定値にフォールバックするようになり、気づくための通知の仕組み（owner/repo#123）と合わせて入れたいため今回は対応を見送ります 🙇」
